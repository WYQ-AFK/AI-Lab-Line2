# 02-代码实验

每个实验一个独立目录，保证**拿到目录即可复跑**。

## 目录约定

```text
exp-<三位编号>-<主题>/
├── README.md        # 目的、环境、运行方式、结论
├── main.py          # 主脚本
├── requirements.txt # 依赖（如有）
└── output/          # 结果图 / 日志
```

## 实验记录要求

1. 写明**运行环境**（解释器版本、依赖版本），否则结论不可复现。
2. 参数用常量或配置文件显式写出，不写死在函数内部。
3. 结论必须由输出或图表支撑，附一段「结果解读」。
4. 失败实验同样保留，标注 `[FAILED]` 与失败原因。
