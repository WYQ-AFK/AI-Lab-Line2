# 03-文献摘记

面向论文与技术文档的精读笔记，强调**用自己的话复述**，避免整段搬运原文。

## 命名规则

```text
<第一作者姓>-<年份>-<短标题>.md
例：He-2016-DeepResidualLearning.md
```

## 单篇结构

1. **一句话结论**：这篇工作解决了什么问题。
2. **动机**：已有方法的缺陷（用公式或数据说明）。
3. **方法**：核心公式 / 结构图（LaTeX 或本地图片）。
4. **实验**：数据集、指标、关键数字（用表格呈现）。
5. **局限与启示**：能否迁移到自己的课题。
6. **原文链接**：DOI 或 arXiv 链接。
