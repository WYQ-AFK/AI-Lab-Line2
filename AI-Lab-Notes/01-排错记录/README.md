# 01-排错记录

记录**真实发生**的问题，按「现象 → 根因 → 修复 → 验证」四段式书写，不写未经验证的猜测。

## 命名规则

```text
YYYYMMDD-<现象关键词>.md
例：20261021-git命令未找到.md
```

## 单篇模板

```markdown
# 20261021 - Git 命令未找到

- **环境**：Windows 11 / PowerShell 5.1
- **现象**：粘贴完整报错原文（含命令）
- **根因**：一句话结论 + 证据
- **修复**：可直接复制的命令
- **验证**：修复后的输出截图或代码块
- **沉淀**：下次如何提前规避
```
